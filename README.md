# Aynen Kardeşim Protokolü (AKP)

> **Uyarı:** Bu depo bir şaka değildir. Şaka gibi duruyorsa protokol çalışıyor demektir.

## Özet

Aynen Kardeşim Protokolü, paket kaybını değil **anlam kaybını** çözmek için tasarlanmış bir uygulama katmanı protokolüdür.
Karşı taraf ne derse desin cevap tektir: onaylayıcı, sıcak ve bilimsel olarak ölçülebilir bir **aynen**.

Laboratuvar testlerinde:
- Anlam çözme oranı: %0
- Sosyal uyum oranı: %97 (±3, çay molasına bağlı)
- RFC numarası: henüz yok, herkes "aynen sonra bakarız" dedi

## Kurulum

```bash
python3 protokol.py
```

Bağımlılık yoktur. İnternet yoktur. Gurur vardır.

## Kullanım

```
SEN > bugün hava nasıl
AKP > aynen kardeşim
SEN > yani güneşli mi
AKP > aynen öyle işte
SEN > ping
AKP > aynen-pong
```

## Mimari

```
[insan] --belirsiz cümle--> [AKP çekirdeği] --aynen--> [yine insan]
```
